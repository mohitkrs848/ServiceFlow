
# ServiceFlow

A multi-tenant field service management SaaS
built for small repair and maintenance businesses.

## Technology Stack

### Backend
- C#
- ASP.NET Core 10 Web API
- Entity Framework Core (planned)
- PostgreSQL (planned)

### Frontend
- React
- TypeScript
- Vite

## Current Features

- [x] Initial backend API
- [x] Health check endpoint
- [x] React frontend
- [x] Frontend-backend integration
- [ ] Authentication
- [ ] Organization management
- [ ] Customer management
- [ ] Service requests
- [ ] Technician assignments
- [ ] Payment tracking

## Local Development

### Backend

dotnet run --project backend/ServiceFlow.Api

### Frontend

cd frontend/serviceflow-web
npm install
npm run dev
